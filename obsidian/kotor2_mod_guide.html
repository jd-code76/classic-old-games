Modding Guide

  1. After you perform a fresh install of the game, run it once to generate some necessary files.
  2. Download and install The Sith Lords Restored Content Mod 1.8.6.
    • Then download the TSLRCM Tweak Pack 1.3 and run it several times, applying however many changes you desire. Note that for TSL Patcher mods like this one, you have to select you game’s install folder. Example: E:\Steam\SteamApps\common\Knights of the Old Republic II
    • Finally, download and extract Silent Sion Restoration into the override folder (example: E:\Steam\SteamApps\common\Knights of the Old Republic II\Override).
  3. Download and extract Robes with Shadows for TSL 1.3.0 into your override folder. Ignore the subfolders and just move the .mdl and .mdx files to your override folder.
  4. Download and extract Ultimate Character Overhaul -REDUX- (TPC version) into your override folder.
    • There are several compatibility patches that you will need later so download them now.
      • TSLRCM Patch
      • K2CP Patch
      • Fixed Hologram Models Patch
  5. Download and install the KOTOR II Community Patch 1.6.2. Note that installer warnings are okay but errors are not.
  6. Download and extract Ultimate High Resolution Texture Pack (TPC version) into your override folder. This updates the textures for Peragus, Telos, Harbinger, and building interiors.
  7. Download and install the remaining Ultimate texture pack mods. Make sure to get the TPC versions!
    • Ultimate Nar Shaddaa
    • Ultimate Dantooine
    • Ultimate Dxun
    • Ultimate Onderon
    • Ultimate Korriban
    • Ultimate Malachor V
  8. Download and install the V2 version of the Droid Special Weapons Fix for TSL 2.0.7.
  9. Download and extract the following into your override folder.
    • Hi-res Beam Effects 2.0.7
    • HD Fire and Ice 2.1
    • Animated Energy Shields
    • TSL Head Model Fixes
    • New Texture of Holocrons in the Telos Secret Academy
      • Choose either the animated or non-animated version.
    • HD NPC Portraits
    • HD PC Portraits
    • Improved Peragus Asteroids
    • Terminal Texture
    • HD RepTab (Workbench)
    • TSL Backdrop Improvements 1.4
      • Install only the files in the “To Override” folder. You will be installing a galaxy map mod later.
    • HQ Skyboxes II TSL
      • Get just the HQSkyboxesII_TSL.7z or HQSkyboxesII_TSL_1k.7z version. Note that this mod uses the TSL Patcher, not the override method!
    • TSL HD Cockpit Skyboxes 3.1
      • High Resolution TPC preferred. Ignore the Nar Shaddaa Realistic Skybox folder.
    • FTL Hyperspace Loop
    • HD Pazaak Cards
      • Copy over all the .tga files in the main folder plus the files in the “green” folder.
  10. Download and install High Quality Blasters 1.1.
  11. Download and extract TSL AI Upscaled Icon Overhaul into your override folder.
  12. Download and install Visually Repair HK-47 1.1. Select the TSLRCM compatible option.
  13. Download and extract each of the following parts for Replacement Loading Screens for KOTOR II into your override folder.
    • Part 1
    • Part 2
    • Part 3
  14. Download and install the TSL Galaxy Map Fix Pack 1.0. Install the vanilla/TSLRCM option.
  15. Download and install Fixed Hologram Models and Admiralty Redux for TSLRCM 1.61. Get just the main file, not either of the patches. Select only the base install option.
  16. At this time, go ahead and extract the UCO patches you downloaded in step 4. Simply copy the files into your override folder and overwrite when asked.
  17. Download and extract TSL Main Menu Widescreen Fix 1.2, making sure to copy the files to the appropriate locations. Copy files from the “FOR OVERRIDE FOLDER” into the override folder. Then copy files from the “FOR TSLRCM” folder into the override folder. Overwrite when prompted.
  18. Download and extract Upscaled Maps to your override folder.
  19. Download and extract Widescreen UI Fix for KOTOR II 4.1 and choose your monitor’s aspect ratio. Then copy the files to your override folder. Make sure to get the correct version for your game (Steam or GOG). Overwrite when prompted.
  20. Download and extract No Vertical Camera into your override folder.
  21. Download and extract K2 Cutscenes Rescaled 1.1.0 into your movies folder, overwriting when prompted. When downloading, choose whichever one matches your monitor’s resolution. You will also need to download the corresponding “_mods” archive. Copy into your movies folder and overwrite when prompted.
  22. Copy the DelDuplicateTGA-TPC.bat script to your game install folder and run it to remove any duplicate TPC files.
  23. Done! Launch the game and test to make sure everything is working up to this point. You can stop here and play the game as is or continue to install other mods.
