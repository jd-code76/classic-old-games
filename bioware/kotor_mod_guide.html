Widescreen Mods

  1. After you perform a fresh install of the game, run it once to generate the necessary files that you will need to make changes to. Afterwards, make a backup of your existing "swkotor.exe" file (rename it to "swkotor.exe.original.bak").
  2. Download and extract KOTOR Editable Executable into your game's install folder (example: "E:\Steam\SteamApps\common\swkotor"). This new "swkotor.exe" is what you will use in future steps. You need this file because the Steam release is encrypted and cannot be patched.
  3. Download and extract Universal Widescreen into your game's install folder.
    • Carefully read and follow the instructions at the URL above!
    • The most important steps are to ensure you selected 1024x768 within "uniws.exe" (you have to select your game's install folder/location (see step 2), you are NOT looking for the .exe file within this program). Also, do NOT click the "Find it for me..." button as it takes a long time. Additionally, this program creates a backup of your editable .exe so you will be able to reference that if you have any issues.
    • Next, ensure your new resolution is above 1440x900 (you can select a lower resolution, but there are additional steps you have to follow that are shown on the page above).
  4. Edit the "swkotor.ini" file (located in your game's install folder) and make the following changes (add the lines if they are not in the file). Feel free to modify the other settings too, to match what is shown in the screenshot.
    • Set "Width" to your monitor's width.
    • Set "Height" to your monitor's height.
    • Set "Frame Buffer = 1" to 0.
    • Make sure "Disable Vertex Buffer Objects" is set to 1.
    • Set or add "RefreshRate=60".
    • Save the file when done.
  5. Download and extract the 4GB patch into your game's install folder (example: "E:\Steam\SteamApps\common\swkotor") then run it to patch your swkotor.exe executable.
  6. STOP AND TEST THE GAME! Do not move on until you have checked your resolution in game and confirmed that it is correct!

    MOST IMPORTANTLY, make sure to limit/cap the framerate to 60 FPS. Otherwise, you will experience the "stuck after combat" bug and other potential issues!
  7. Next, install Ultimate Character Overhaul (UCO) and the Community Patch.
    • First, download and extract Ultimate Character Overhaul -REDUX- to your "Override" folder (create one if it doesn't exist).
      • Example: "E:\Steam\SteamApps\common\swkotor\Override". Note: There should NOT be any folders within the "Override" folder. All files must be "loose" and yes, it gets ugly once you've installed a bunch of mods.
    • Next, download and install KOTOR 1 Community Patch 1.10.1.
      • This uses an installer called HoloPatcher. Simply run the installer and select your game's install folder (see step 5 for example). Note that this will take a while to complete (10-15 mins). Also note that the installer creates a backup folder in the same location it was run. So if something goes wrong and you need to restart, you can use that folder to replace your original files as needed.
    • Now download the UCO compatibility patch for the K1 Community Patch and extract to your override folder.
      • Per the instructions, install order: UCO -> K1CP -> Compatibility patch (overwrite if asked); the compatibility patch must be installed after installing both UCO and K1CP.
  8. Download and extract HUD Corrections into your game's install folder.
    • Extract the folder that corresponds to the resolution you patched earlier (example: If you entered 2560x1440 in the uniws.exe patcher, you must pick 2560x1440 as the folder in this step).
    • Move all the extracted files within the folder you chose into the override folder.
  9. Download and extract K1 High Resolution Menus 1.5 into your game's install folder.
    • Find your monitor's aspect ratio and move the corresponding GUI files from the folder you just extracted into your "Override" folder. Example: If your monitor's aspect ratio is 16x9, you must open that folder, find the folder that contains your monitor's resolution (2560x1440, as an example) and move the files within that folder into your "Override" folder. Overwrite any files if asked.
    • Move the patcher files ("hires_patcher.bat", "hires_patcher.exe", and "hires_patcher.pl") into your install folder and run "hires_patcher.bat", then follow the prompts. Consult the readme if you have any questions or issues.
  10. STOP AND TEST THE GAME! DO NOT MOVE ON UNTIL YOU HAVE CHECKED YOUR RESOLUTION IN GAME AND CONFIRMED THAT IT IS CORRECT!
  11. Download and extract HD UI Menu Pack 1.1 into your "Override" folder.
  12. Download and extract Widescreen Cockpit and Racing Track on Manaan 0.22 into your game's "Override" folder. Overwrite any files if asked.
  13. Download and extract KOTOR 1 Widescreen Fade Fix 1.0.2. Find the file in the folder that matches your chosen resolution (similar to step 8), put it into your game's "Override" folder and overwrite any files if asked.
  14. Download and extract K1 Main Menu Widescreen Fix 1.2. Put the files in the "For Override" folder into your game's "Override" folder. Additionally, you may pick ONE of the optional logos and put that into your "Override" folder too.
  15. Download and extract HD Menu and UI Assets 1.0 into your "Override" folder and overwrite any files when asked.
  16. Done! Launch the game and test to make sure everything is working up to this point.

Texture Mods

  1. After you perform a fresh install of the game or are continuing after having installed widescreen mods, the following mods may be downloaded and installed by extracting the files into your game's "Override" folder.
    • Pretty Good! Icons for KOTOR 1.0 - The TPC version is recommended.
    • High Quality Cockpit Skyboxes 1.0 - The XL version is recommended.
    • High Quality Skyboxes II
    • Animated Energy Shields 1.0.0
    • High Quality Stars and Nebulas 1.2
    • Hi-res Beam Effects 2.0
    • HD Fire and Ice 2.1
    • Terminal Texture 1.0.0
    • Upscaled Computer 1.0.0
    • HD Pazaak Cards 1.0.0
    • RepTab (workbench) HD 1.0.0
    • Loadscreens in Color
    • K1 Cutscenes Rescaled 1.5.1
      • This mod does NOT go into the override folder, it goes into the "movies" folder instead. Overwrite when prompted. You may choose alternative versions from the "alts" folder if you desire.
  2. The following are complete texture improvements (hi-res) for each of the game's locations. Make sure to download only the .tpc versions. Overwrite any files if asked.
    • Ultimate Endar Spire-Star Forge-Yavin Station
    • Ultimate Taris
    • Ultimate Dantooine
    • Ultimate Tatooine
    • Ultimate Kashyyyk
    • Ultimate Manaan
    • Ultimate Korriban
    • Ultimate Unknown World
  3. Next are mods specific to the Ebon Hawk. Effectively, an improved texture mod and an animated galaxy map screen.
    • Ultimate Ebon Hawk Repairs 2.0.0
      • Make sure to move the main files over first then move the animated monitors content and overwrite when prompted.
    • K1's Ebon Hawk Animated texture 1.0.0
  4. These next couple of mods increase the resolution of the portraits.
    • HD PC Portraits 1.0
    • HD NPC Portraits 2.0
  5. Download and install High Quality Blasters 1.1. Note that it does NOT use the override method, it uses the TSLPatcher which requires you to select the install location, for example: C:\Games\swkotor.
  6. These last few mods add some much needed QoL and general improvements without ruining the intended experience.
    • Logical Datapads 1.0.0
      • This mod utilizes the TSLPatcher method. It's okay if you receive warnings.
    • K1 Galaxy Map Fix Pack 1.1 (also download the HR Menu Patch)
      • Same as above, this uses the TSLPatcher. Select the vanilla version (default).
      • When installing the HR Menu Patch, select the folder that corresponds to your monitor's aspect ratio then select the resolution that matches your monitor.
    • JC's Security Spikes for K1 1.2.2
      • Uses TSLPatcher. Install whichever version you desire.
  7. Download and copy the DelDuplicateTGA-TPC.bat script to your game install folder and run it to remove any duplicate TPC files.
  8. Done! Launch the game and enjoy one of the best Star Wars games ever made.
